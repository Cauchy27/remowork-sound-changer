# レポート・文書のデザイン基準

人が読むレポート・文書・スライドの見た目を決めるときに読む。色・書体・余白を都度考えず、本書の値を既定として使う。アプリの画面は対象外で、`DESIGN.md` と design 系のスキルに従う。AI が読むだけの文書（SKILL.md、作業メモなど）と、チャット投稿にも適用しない。

## 位置づけ

本書は[デジタル庁デザインシステム](https://design.digital.go.jp/dads/)（以下 DADS）を参考にしたローカル規定で、DADS そのものではない。DADS の対象はウェブサイトやサービスで、文書・スライド向けの公式指針は確認できなかった（2026-11-02 時点。サイト全文の ZIP は未検索）。媒体への読み替え、見出しへのサイズの割当、余白の段階は本書の判断である。

DADS は導入先がキーカラーなどを差し替えて使う前提で、差し替えても維持する要件を定めている。本書も同じ考え方で、変えてよい値と変えてはいけない下限を分ける。

## 優先順位

1. 依頼者の明示指定、提出先の指定様式、相手先のブランド
2. プロジェクトの `DESIGN.md`、案件で統一した様式（既存テンプレート）
3. 本書の既定値

1・2 があるときは、キーカラー、書体、サイズの段階をその指定に合わせてよい。次節の下限は 1・2 があっても守る。ブランド色や案件様式が下限に届かないときは、色の濃さなどを調整して下限に合わせる。提出先が様式を固定していて変えられないときだけ、その様式に従い、届かない箇所を報告に書く。

## 下限

| 項目 | 下限 |
|---|---|
| 文字と背景 | コントラスト比 4.5:1 以上。文字の大きさによる緩和は使わない（ロゴは対象外） |
| 罫線・図形・グラフの線 | 隣接する色に対して 3:1 以上。届かないときは近くに 4.5:1 以上の文字を置く |
| 色の意味 | 色だけで情報を区別しない。成功は緑、エラーは赤、警告は黄か橙の対応を変えない |
| 本文の文字 | 16 CSS px（12pt）以上。表と注記は 14 CSS px（10.5pt）まで下げてよい（分割できない自動変換の表だけ例外。「表」の節を参照） |
| 行の送り | 本文はフォントサイズの 1.5 倍以上 |
| 構造 | 見出しの階層を飛ばさない。空白文字で位置を揃えない。長文を斜体にしない。文字を画像にしない |

## 色

既定のキーカラーは青。ブランド色があれば差し替える。差し替えた色を文字に使うときは、白地と淡い背景の両方で 4.5:1 を確かめる。

| 役割 | 値 | DADS の名称 | 白地との比 |
|---|---|---|---|
| 見出しの文字 | `#1a1a1a` | gray-900 | 17.40 |
| 本文の文字 | `#333333` | gray-800 | 12.63 |
| 補足の文字 | `#666666` | gray-600 | 5.74 |
| 背景 | `#ffffff` | white | なし |
| 淡い面、表の縞 | `#f2f2f2` | gray-50 | 1.12 |
| 表の見出しセル | `#e6e6e6` | gray-100 | 1.25 |
| 罫線（白地） | `#949494` | gray-420 | 3.03 |
| 罫線（淡い面に接する） | `#7f7f7f` | gray-500 | 4.00 |
| キーカラー | `#0031d8` | blue-800 | 8.64 |
| リンク（下線つき） | `#00118f` | blue-1000 | 14.22 |

状態を示す色は次の組で使う。文字の列は白地と淡い背景のどちらでも 4.5:1 以上になる値を選んだ。線・アイコンの列は白地の上で使う値で、4.5:1 に届かないものがあるので文字に使わない。淡い背景の上の線には文字の列の色を使う。

| 状態 | 文字 | 線・アイコン | 淡い背景 | 淡い背景との比 |
|---|---|---|---|---|
| 成功 | `#197a4b` | `#259d63` | `#e6f5ec` | 4.75 |
| エラー | `#ce0000` | `#ec0000` | `#fdeeee` | 5.14 |
| 警告（黄） | `#806300` | `#b78f00` | `#fbf5e0` | 5.20 |
| 警告（橙） | `#ac3e00` | `#fb5b01` | `#ffeee2` | 5.40 |
| 情報 | `#0031d8` | `#0031d8` | `#e8f1fe` | 7.59 |

比は WCAG の式で本書が計算した値で、公式の掲載値ではない。DADS の `semantic-*-1`・`-2` の用途の区分は公式に確認できなかったため、本書では文字に使える値を色相の中から選び直している。

## 文字

書体は `'Noto Sans JP', sans-serif`、等幅は `'Noto Sans Mono', monospace`、太さは 400 と 700 の 2 段階とする。使えない環境では OS の日本語ゴシック体でよい。フォントファイルを資料と一緒に配らない。

| 役割 | HTML | Doc・Word・PDF | 行の送り | 字間 | 太さ |
|---|---|---|---|---|---|
| 文書タイトル | 32px | 24pt | 1.5 | 0.01em | 700 |
| 見出し 1 | 24px | 18pt | 1.5 | 0.02em | 700 |
| 見出し 2 | 20px | 15pt | 1.5 | 0.02em | 700 |
| 見出し 3 | 17px | 13pt | 1.7 | 0.02em | 700 |
| 本文 | 16px | 12pt | 1.75 | 0.02em | 400 |
| 表 | 16px（列が多いときは 14px） | 10.5pt | 1.7（14px は 1.3） | 0 | 400 |
| 注記・出典 | 14px | 10.5pt | 1.5 | 0 | 400 |

pt は 1 CSS px = 0.75pt で換算した（17px は 13pt に丸めた）。文書ツールの倍数指定は書体の行高に掛かるため、行の送りが上の値になるかを出力で確かめる。

本文の 1 行は全角 40 字程度を目安にする。HTML は本文の幅を `max-width: 42rem` とし、A4 縦は左右の余白を 20mm にすると 12pt で約 40 字になる。

## 余白

基準は 8px（6pt）で、要素の間隔は 8 / 16 / 24 / 40 / 64px（6 / 12 / 18 / 30 / 48pt）の 5 段階から選ぶ。段落の間は 16px（12pt）。同じ種類の要素には同じ間隔を使い、関連が強いほど狭く、弱いほど広くする。見出しは階層が上のものほど上の余白を広くする。

## 表

- 見出しセルは太字にし、背景は `#e6e6e6`、文字は `#1a1a1a` とする
- 文字は左揃え、数値と日付は右揃え、縦は上揃えとする
- 罫線は 1px で、縞を使うときは偶数行を `#f2f2f2` にする
- セルの内側の余白は DADS のサンプルに合わせて 12px 16px を基本とし、行数が少ない表は 20px 16px にする
- 結合セルは最小限にし、1 レコードを 1 行に収める
- 名前と値の対だけなら表にせず、箇条書きにする。レイアウトの目的で表を使わない
- 列が多い表は、文字を小さくする前に分割か横置きを検討する。分割できない自動変換に限り 9pt まで下げてよい

## 図とグラフ

グラフの公式の部品と系列色はない。下限をそのまま適用し、次を守る。

- 色に加えて、直接のラベル、線種、マーカーのいずれかで系列を区別する
- 系列は 4 つまでにし、`#0031d8`・`#c74700`・`#197a4b`・`#4d4d4d` から順に使う（本書の判断）
- 目盛線が 3:1 に届かないときは、近くに 4.5:1 以上の文字を置く
- 元データの表か説明文を添える

## 媒体ごとの適用

| 媒体 | 適用すること |
|---|---|
| Markdown | 色やサイズは指定しない。見出しの階層、表の揃え（数値の列は `---:`）、状態を色や絵文字だけで示さないことを守る |
| HTML | 色と文字の値を CSS 変数にする。Noto Sans JP を読み込み、`lang="ja"` を付け、表の見出しに `<th scope="col">` を使う。文字色を指定したら背景色も指定する |
| Google Doc・Word・PDF | pt の列を使う。A4 縦で左右の余白は 20mm。ページ分けなしの長い Doc でも同じ値を使う |
| スライド | 色の表を使う。サイズと太さは投影用なので slide-creation の目安に従う。下限のうち文字の大きさ以外を守る |

## してはいけないこと

- デジタル庁のロゴ、シンボルマーク、政府の紋章や標章を資料に載せない。DADS の利用条件の対象外で、ロゴの使用は限られた場合の申請制である
- デジタル庁や国が作成した資料に見える書き方をしない。作成者を資料に明記する
- 資料に「DADS 準拠」「デジタル庁認定」と書かない

## 出典

本書の色や文字組みを使っただけの資料に、出典を書く必要はないものとして扱う。公式に要否の記載がないため、社外向けで迷うときは法務に確認する。

DADS の文章、図、コードを資料へ転記するときは、公式の例に倣って出典を書く。加工したときは、加工した旨と作成者も書く。

```text
出典：デジタル庁デザインシステムウェブサイト https://design.digital.go.jp/dads/
デジタル庁デザインシステムウェブサイト https://design.digital.go.jp/dads/ をもとに〇〇株式会社作成
```

本書は、デジタル庁デザインシステムウェブサイト <https://design.digital.go.jp/dads/> のコンテンツを加工して作成した。色と文字の値は `@digital-go-jp/design-tokens` 2.1.0（MIT License、Copyright (c) 2023 デジタル庁）から写した。

## テンプレート

レポートの種類に合うものがあれば、[レポートのテンプレート](report-templates/README.md)を使う。HTML 8 種と、Markdown で書くときの見出し構成を置いている。

## 版と再確認

参照した版は、DADS β版 v2.18.2（2026-10-21）、design-tokens 2.1.0、利用上の注意事項 Rev 003（2026-08-05）で、確認日は 2026-11-02 である。

DADS はβ版で、値が変わることがある。資料を作るたびに公式を読みに行かず、本書の値を使う。本書を更新するときは、配布パッケージの `tokens-simple.css` と値を照合し、コントラスト比を計算し直す。値を写している先は、`report-templates/`、html-spec-generator のテンプレート 2 本、report-publish の `md2doc.py`、slide-creation の `reference.md` で、これらも合わせて直す。
