# このリポジトリの用語

[人向けの文章の用語](plain-terms.md)の、このリポジトリ版の追記。人向けの文章を書くときに、共通の表と一緒に使う。共通の表と食い違うときは、この文書を使う。

- ひな形の変更を各リポジトリへ配るとき、この文書は上書きしない。リポジトリごとに書き足す。
- 載せるのは、人が決めた語だけ。AI が案を出すときは、まずこのリポジトリの用語辞書（あれば）を grep し、決まっていない語だけを一覧にして人に決めてもらう。
- 案を出す前に、このリポジトリで多い語を数える（例: `git grep -c "<語>" -- '*.md'`）。言い換え表の中身はリポジトリごとに違う。

## 1. 社内の呼び名の短い説明

人向けの文章で呼び名を使うときは、初めて出る所でこの説明を添える。説明が要らないように普通の言葉で書けるなら、そうする。

| 呼び名 | 短い説明 |
|---|---|
| （例）P0／P1 | レビューの指摘の重さ。P0 は直さないと出せない、P1 は今回直す |
